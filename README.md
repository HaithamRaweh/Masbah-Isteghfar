# تطبيق مسبحة الاستغفار الفائق (754 صيغة)

هذا المجلد يحتوي على تطبيق مسبحة إلكترونية متكامل وجاهز للرفع على أي استضافة مجانية (مثل Netlify Drop أو Vercel أو GitHub Pages) أو مشاركته كرابط ويب تفاعلي.

### محتويات المجلد:
1. `index.html`: الصفحة الرئيسية للتطبيق (تحتوي على كامل الـ 754 صيغة بالتسلسل والتصميم العصري).
2. `manifest.json`: إعدادات تثبيت التطبيق على هواتف أندرويد و iOS (PWA).
3. `icon.svg`: أيقونة التطبيق.

### طريقة النشر والاستخدام:
- قم برفع هذا المجلد (أو استخراج ملف الـ zip) على موقع [Netlify Drop](https://app.netlify.com/drop) للحصول على رابط مباشر فوراً.
- افتح الرابط من متصفح جوجل كروم على هاتف الأندرويد، واضغط على خيار "الإضافة إلى الشاشة الرئيسية" ليتم تثبيته كتطبيق مستقل على الهاتف.
